Understanding the notation

Little-o: f(n) = o(g(n))f grows strictly slower than g in the limiting sense: f(n)/g(n) approaches 0 as n approaches infinity.
Little-omega: f(n) = ω(g(n))f grows strictly faster than g in the limiting sense: f(n)/g(n) approaches infinity as n approaches infinity.
RememberA bar chart at one input size illustrates values only. Asymptotic claims depend on behaviour as n becomes very large.

Example: n = 8

At n = 8, n = 8, n² = 64, n³ = 512, and 2ⁿ = 256. The cubic function is larger than the exponential function at this particular input, but 2ⁿ eventually outgrows n³ as n increases.

For large n, exponential functions can grow much faster than polynomial functions. Use the input control to explore how the displayed values change. Values are capped at n = 20 to keep the chart readable.
