Little o & Little ω

An interactive visual lab for understanding strict asymptotic growth. Follow both the function curves and the ratio that defines the relationship.

1. Little-o: slower growth

Example: n = o(n²). The ratio n/n² = 1/n approaches 0 as n grows.

Function comparison

f(n) = n and g(n) = n²

f(n) / g(n) → 0

Interpretation

The linear function becomes negligible compared with the quadratic function.

2. Little-omega: faster growth

Example: n² = ω(n). The ratio n²/n = n grows without bound as n grows.

Function comparison

f(n) = n² and g(n) = n

f(n) / g(n) → ∞

Interpretation

The quadratic function increasingly dominates the linear function.

3. Explore different input sizes

Change the maximum n shown on the graphs. Watch how the ratios change as the input range grows.

Key idea: A single bar chart compares values at one input size. These line graphs plus ratio graphs communicate the asymptotic idea more directly. The examples illustrate the definitions; a finite graph alone is not a formal proof.

Definitions at a glance

Little-o

f(n) = o(g(n)) when f(n)/g(n) → 0 as n → ∞, for the examples shown here.

Little-omega

f(n) = ω(g(n)) when f(n)/g(n) → ∞ as n → ∞, for the examples shown here.
